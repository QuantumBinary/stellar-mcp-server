# Contributing to Stellar MCP

Thank you for your interest in contributing to the Stellar MCP project!

To avoid documentation drift and maintain a single source of truth, our comprehensive contribution guidelines, code style rules, and pull request workflows are hosted on our documentation site:

👉 **[Read the Official Contributing Guide](https://docs.syron.tech/docs/contributing)** (or view the source in [`apps/docs/content/docs/contributing.mdx`](../apps/docs/content/docs/contributing.mdx)).

---

## Quick Contribution Workflow

1. **Find an Issue**: Browse open issues on [GitHub Issues](https://github.com/QuantumBinary/stellar-mcp-server/issues). Look for issues labeled `good first issue` or `help wanted`.
2. **Branch**: Create a feature branch off `main` (`git checkout -b feat/your-feature-name`).
3. **Develop & Test**: Implement your changes and verify that all tests pass (`npm test`) and code passes lint checks (`npm run lint`).
4. **Pull Request**: Open a pull request against `main` with a clear description and a standalone `Closes #<issue_number>`.

For full details, please refer to the [documentation site](https://docs.syron.tech/docs/contributing).
